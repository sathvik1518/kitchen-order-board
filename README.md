# kitchen-order-board

A kitchen order board built only from a small set of reusable components (`Button`, `Input`, `Card`, `Modal` on the native `<dialog>`, `Stack`, `PageLayout`): search, a "Mark ready" button with a loading state, and a cancel confirmation, connected to TanStack Query.

```bash
npm install
npm test
npm run dev
```

See `DOCUMENTATION.md` for the full write-up.
